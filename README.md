# Fibonacci em Assembly MIPS

## Descrição

Algoritmo desenvolvido em Assembly MIPS que recebe um número natural entre 3 e 34 e gera a sequência de Fibonacci.

A cada iteração, realiza a subtração dos dois últimos termos (último - penúltimo) e imprime somente os resultados ímpares.

## Funcionamento

- Solicita um número ao usuário.
- Verifica se o número está dentro do intervalo permitido.
- Gera a sequência de Fibonacci.
- Calcula a diferença entre os dois últimos termos.
- Exibe somente os resultados ímpares.

## Tecnologias

- Assembly MIPS
- Simulador MARS/SPIM
